# ESPN

A synchronized sports channel built from the working FSN scaffold, with a separate game pool and its own highlight arrangement.

## Channel rules

- Major/professional sports focus.
- Full-game windows stay synchronized for viewers.
- ESPN uses a different source rotation from FSN.
- Daily schedules reseed at local midnight and the source order changes week to week.
- Dedicated highlight-mix windows are placed into the day instead of using FSN's single 5–6 PM fallback bench.
- Source failures do not silently reshuffle viewers onto another scheduled game.
- Shared channel remote is loaded from the common channel-list script.
- Share control keeps the existing 1/10 StarCoin progress convention.

## Current rotation

The initial pool mixes classic full NFL, NBA Finals and Stanley Cup games from official/verified league or ESPN YouTube sources. Highlight windows rotate shorter official sports recaps.
